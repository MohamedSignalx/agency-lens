# Agency Lens · ADHD session

One place. Pin a UDL 3.0 kit, then paste it into a chat, a doc, code, or Apps Script.

This folder is a snapshot of what is pinned right now. Change the kit on the board, then download again.

## Do this

1. Stay on the board. The ADHD kit is ready. Change it only when this session needs a different set.
2. Copy the chat card. Paste it as the first message in Grok, Gemini, Claude, or any chat.
3. Put `system-instruction.txt` in custom instructions, a Gem, or a Project if you do not want to paste it every time.
4. The line that starts with `udl:` is the kit ID. Drop it in a file, a comment, or a prompt.
5. When the kit changes, download the package again.

## Files

| File | Where it goes |
| --- | --- |
| chat-card.txt | First message of a chat |
| system-instruction.txt | Standing instructions |
| checklist.md | A doc or a GitHub issue |
| agency-lens.ts | A code file |
| agency-lens.gs | Google Apps Script, then run insertBannerIntoActiveDoc |
| agency-lens.json | Any tool that reads JSON |
| kit.tsv | File → Import in Google Sheets, only if you want a table |

A sheet is a table of the kit. The board is where you design it.

## How a reply should look

No dense paragraphs. One anchor per line.

- CRITICAL ACTION — do this now
- NEXT STEP — the next move
- CODE REFERENCE — the file or the line
- RISK / WARNING — what breaks, and the fix
- STILL BENDING — unfinished
- EXECUTIVE SIGNAL — the point, in one sentence

Not a CAST product. Wording follows the CAST (2024) UDL Guidelines 3.0, including the public Arabic organizer.
